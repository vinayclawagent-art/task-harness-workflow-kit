# Task Harness Workflow Kit

Use this draft when a recurring task is too mature for one-off prompting but not yet proven enough to become a promoted skill.

1. Define trigger, inputs, context, allowed tools, and output contract.
2. Include one worked example.
3. Run the workflow on a real task.
4. Promote to a Hermes skill only after successful repetition.

Pitfall: do not duplicate existing Hermes skills; use workflow drafts as staging areas.


## Verification
- Run on a real VinClawLabs task.
- Record paths changed and evidence.
- Promote only if it remains distinct from existing skills.
