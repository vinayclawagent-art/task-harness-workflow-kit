# Task Harness Workflow Kit

A lightweight workflow.md template for turning recurring agent tasks into repeatable harnesses before promoting them into full Hermes skills.

Inspired by: https://x.com/trq212/status/2061907538741006796

## What it contains
- `artifact-package/` — Obsidian package note
- `prototype/` — concrete markdown prototype
- `skill-draft/` — reusable procedure draft
- `improvement-loop/` — recurring improvement tracker

## Quickstart
Read `prototype/README.md`, then fill the included template against one real workflow.

## Latest improvement
- 2026-06-11: Added `prototype/Release Candidate Post-Trial Debrief Template.md` so the next real release-candidate QA pass turns intake, traceability, trial-packet, and decision-card evidence into explicit package, prototype, workflow-builder, skill-draft, and handoff patch decisions. This is template-ready, not validation-complete.

## Decision standard
Do not promote the workflow harness or patch the skill draft until a real release-candidate trial has completed the kickoff card, evidence intake card, trial packet, decision card, and post-trial debrief with source-backed links.

## Roadmap
- Run the prepared release-candidate packet on a real Mission Control release candidate.
- Fill the post-trial debrief before changing package/prototype/skill wording.
- Promote or merge the skill draft only after reuse produces evidence.
